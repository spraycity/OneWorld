# Accessibility Requirements

- Full keyboard navigation and visible focus.
- Screen-reader labels for language selectors, microphone state, transcript, and controls.
- Live transcript updates must not overwhelm screen readers; provide configurable announcement behavior.
- Text resizing and high-contrast support.
- Captions/transcripts for all translated speech.
- Avoid color-only status indicators.
- Adjustable speech rate and volume.
- Clear error messages and a text-only fallback.
- Test with users who have hearing, vision, motor, and cognitive access needs.
